The one number this pipeline cannot measure

What each ceiling would admit

An adaptor design does not make an antigen safer — the adaptor still binds it — it makes the exposure stoppable. How much risk that justifies is a clinical policy decision, not something derivable from expression data, so the ceiling is a declared input and this is what every setting of it buys. The declared value is highlighted.
